# R1 adversarial attack — lens `fi_method` (Fisher-information methodology)

_2026-09-27. Adversarial agent. Target: the NMR echo window "R1" (research/CURRENT_STATE.md). Everything here is reproducible from the scripts in this folder (single-threaded, ≈ 17.5 CPU-min in total, every run < 6 CPU-min and < 0.5 GB). Nothing outside this folder was modified. Tags: MEASURED (computed here), DERIVED (algebra or reanalysis of measured numbers), LITERATURE-SUPPORTED (source checked), INFERENCE, UNPROVEN._

## Verdict: WEAKENS

The lead's headline numbers come from an idealised measurement model: f_hard 0.55–1.0, echo FI 10–160× the transfer FI, and gains up to 10⁴. That model has constant σ, perfect time reversal, γ = 0 for the echo, a single parameter with everything else known, and a classical analyst who discards all data after t_c.

- **Theoretical level: the window survives.** Replacing the gate's partition with a correct estimator-level statistic (the fit bias of the truncated classical model versus the Cramér–Rao bound) does **not** erase the window at σ = 0.01.
- **Practical level: the window is effectively erased.** Once the echo includes the experimentally unavoidable Loschmidt-echo attenuation (T3 ≈ T2/0.15, literature-anchored), or the dephasing the project itself uses as its embedding proxy, the value of the hard window falls to a median joint gain of ≈ 1.0–1.5. The echo FI also falls **below** the transfer FI.
- This is a KILL only *conditional* on the T3 ∝ T2 law holding for protein ¹H networks and local OTOCs. That link is INFERENCE, so the verdict is WEAKENS, not KILLS.

## Tests and key numbers

1. **EB: estimator bias on the C2 ε ladders** (`estimator_bias.py` → `estimator_bias_N10_8.json`, log). Per ε and observable: gate t_c, D(T), single-parameter bias/sd, norm-correction and polynomial nuisance fits (no oracle), MSE-optimal gain, and M* under each criterion.
   - N = 10 p19, ε = 1e-4, echo: t_c^gate = 4. The window with D ≤ 0.5 ends at index 3, with polynomial nuisance at index 7, with norm-correction nuisance at index 5.
   - Nuisance-absorbing fits extend the classical window about 2× in time but not to the full window (MEASURED).
2. **FIT: actual nonlinear fit at N = 8** (`n8_fit.py`, models ε = 1e-3, 3e-4 and w = 4). ε = 3e-4 echo fitted bias: −0.100 / −0.003 / −0.081 / −0.006 Å, which is 6.0 / 0.6 / 3.9 / 1.3 sd. So a real parameter-level classical deficit exists at σ = 0.01 for failing models, but it is 5–100× smaller than the gate gain (MEASURED).
3. **NOISE: reversal attenuation and ratio noise** (`noise_models.py`, `t2_estimate.py`). The C3 kill (median f_hard < 0.3) fires for HN at T3 ≤ 500 µs and overall at T3 ≤ 200 µs (t_c recomputed). The joint gain drops below 1.5 for dense at T3 ≲ 130 µs (DERIVED).
4. **DEPH: dephased echo** (`dephased_echo.py`), see F5.
5. **NUIS: structural meaningfulness** (`nuisance.py`, Jacobians in `nuisance_jacobians.npz`), see F8.
6. **FD / GRID** (`fd_grid_checks.py`), see F9 and F10.
7. `summarise.py` → `summary.json`: calibrated fit gains, per-job anchored attenuation, per-experiment accounting, dephasing restricted to the gate panel.

## Claim levels

- **Theoretical (idealised isolated cluster, perfect reversal, known nuisance, σ = 0.01):** a classical deficit exists at the parameter-estimation level. Its size is 1.2–71× in repetitions at N = 8 for the failing models, not 10²–10⁴. At N = 10 it is closed or marginal for ε = 3e-5 (D ≈ 1.2–1.4). The lead then rests entirely on C2/C3 scaling, which this lens does not weaken (MEASURED / DERIVED).
- **Practical (a real NMR echo experiment):** with literature-anchored reversal attenuation, the per-experiment joint gain has a median of 1.05–1.12 (max 2.75), and the hard window adds at most one structurally determined coordinate direction. The claim category "quantum usefulness" is not supported at practical level L0. This rests on INFERENCE: R = 0.15 transferred from a non-protein solid and applied to local OTOCs.
