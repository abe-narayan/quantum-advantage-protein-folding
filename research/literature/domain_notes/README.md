# Domain evidence notes (raw, archived)

Raw evidence notes from the six parallel literature searches (2026-09-26), preserved as research metadata. `LIT_RULES.md` holds the search and verification rules each search followed. The synthesis files one level up are the reviewed products. These notes hold the full per-paper fields, the 16-question primitive analyses, and the search logs.

Key mapping:
- `lit_A_sampling.md` numbers papers P1–P80; these map to bibliography keys A1–A80.
- Every other file uses its own B/C/D/E/F keys directly.

Tags inside the notes:
- **I(agent)** or **I(prog)** marks an estimate, not a literature claim.
- Items in section 9 ("Unverified leads") must not be cited.
